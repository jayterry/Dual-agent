# agent_full_coverage — 全流程煙霧測試

## 目的

以單一 `scenarios.json` 覆蓋 Dual-agent **現有主要流程**，作為新修復／新 skill 的回歸基線（與 `pending_review_無法取消` 等問題導向劇本並存）。

## 覆蓋矩陣

| 層級 | scenario id | 類型 | 涵蓋 |
|------|-------------|------|------|
| Ingress | `ingress_review_and_action` | ingress | 審查候選、mixed 送審、複合 action、SMS share、拒絕句 |
| Semantic Router | `router_golden_skills` | semantic_router | weather、search_web、open_url、fetch_url、call_dai、複合句、假設問句 |
| Semantic Router | `router_apply_override` | semantic_router | 覆寫錯誤 Planner todos |
| Validate | `validate_meta_and_review` | validate | meta 不搜尋、pending_review 校正、明文搜尋保留 |
| CAI 短路 | `cai_identity_and_greeting` | plan_execute_multiturn | 你是誰、你好（不進 Planner） |
| CAI 送審 | `cai_review_entry_ask` | plan_execute_multiturn | 意圖無正文 → ask_user + pending_review |
| CAI 待審 | `cai_pending_review_lifecycle` | plan_execute_multiturn | 進入→放棄→改天氣（回歸） |
| CAI→DAI | `cai_review_to_dai` | plan_execute_multiturn | ask_user → 補正文 call_dai |
| CAI→DAI | `cai_scam_url_direct` | plan_execute_multiturn | 一輪 mixed 送審 |
| CAI 複合 | `cai_compound_weather_url` | plan_execute_multiturn | weather + open_url 多步執行 |
| Memory | `memory_relation_recall` | memory_multiturn | 記住→確認→回想 |

### CAI Skills（經 router / multiturn 觸及）

| Skill | 覆蓋方式 |
|-------|----------|
| ask_user | 送審進入、validate |
| call_dai | router、review_to_dai、scam_url |
| weather | router、pending_review、compound |
| search_web | router |
| open_url_readonly | router、compound |
| fetch_url | router |
| instant_answer / open_app / confirm | 由 pytest 覆蓋；本劇本以 router+validate 為主，E2E 可加 `--live` |

### DAI

- `call_dai` + mock `execute_step: call_dai_success` 驗證 CAI→DAI 鏈與 Replan 收尾
- 完整 7 步 DAG 見 `tests/test_guard_pipeline.py`、`tests/test_call_dai_skill.py`

## 執行

```bash
cd Dual-agent

# 審計（不需 Ollama）
python scripts/run_problem_reports_audit.py

# 對話紀錄（預設 --problem agent_full_coverage）
python scripts/run_test_dialogue.py --skip-pytest

# 真實 LLM（僅 plan_execute_multiturn 段落）
python scripts/run_test_dialogue.py --live --skip-pytest
```

## 劇本分組

- **baseline**：歷史／黃金路徑重現
- **experimental**：邊界與延伸（複合句、兩輪送審、回想）
- **control**：無 bug 脈絡對照（打招呼、直接天氣、低信心 router）

## 狀態

- `status: open` — 審計持續執行；穩定後可改 `fixed` 作發布基線

## 已知限制

1. **mock 管線**不經真實 `invoke_planner` 內的 semantic_router；router 覆寫由獨立 `semantic_router` scenario 驗證
2. **`/v1/review`（run_dai_then_replan）** 未納入 multiturn；見 `tests/test_review_display.py`
3. **open_app / confirm** 需桌面環境；建議 Ollama E2E 或人工抽測
